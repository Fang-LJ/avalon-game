# 无损 PNG v2 与等待大厅精简

## 原稿与导出

唯一母版是本地 `design-source/cards/01-actions.png`、`02-special.png`、`03-roles.png`。
三张均为 1448×1086、RGB、PNG；大小分别为 2,712,484 / 2,675,739 / 2,770,026 字节。
没有读取 v1 JPEG 或 contact sheet 作为导出源，没有 resize 母版、改变裁切坐标或卡框比例。

19 张采用原 PNG → crop → 2× LANCZOS → RGB PNG（optimize，compress_level=9）。
没有调色板量化、重度锐化、AI 补细节或其他有损编码。每张保存后解码，逐字节验证
解码像素与待保存像素相同。压缩编码无损，但 2× 插值本身不创造新的真实细节。

本地人工检查了原生 crop / 2× PNG 的 A/B（梅林、成功牌、身份卡背）及 19 张总览，
未见明显文字变形、强烈 halo 或装饰缺失，选择 2× 输出以预先完成高 DPI 放大。
A/B 与总览位于已忽略的 `design-source/cards/export-ab-v2/` 与
`design-source/cards/export-contact-sheet-v2.png`；不会塞入小程序或当作正式母版。

## 发布与权限

复用既有 `playmate-minio` 与 `avalon-assets` Bucket，没有新建 Bucket，也没有重启服务。
发现旧策略只允许匿名读取 `cards/v1/*`，v2 公网最初返回 403；经用户明确批准，
只增加 `cards/v2/*` 的匿名 `s3:GetObject`，没有 ListBucket、上传或删除权限。
原权限及 v1 的发布前后 SHA-256 保存在：
`/opt/avalon-game/static-assets-backups/cards-v2.mJbcqQq6/`。

19 张 v2 已发布为 image/png、public / max-age=31536000 / immutable。
公网逐张 HEAD / GET 200、Content-Type、缓存及内容 SHA-256 检查均通过；
v1 的 19 张也全部重新 HEAD / GET 验证，与仓库原件一致，服务器发布前后哈希相同。
匿名桶列表仍为 403。遇到已存在的 v2 对象但字节不同，脚本拒绝覆盖。
遇到非预期 Bucket 策略，脚本拒绝替换。临时上传目录已清理。

发布先于切换：生成 → 上传 → 验证全部 v2 → 修改 CARD_BASE。
local / prod、develop / trial / release 继续复用同一 HTTPS base：
`https://api.playmatespace.cloud/avalon-assets/cards/v2`。
19 个前端 URL 全部是 PNG；play-card 诊断日志、UI 尺寸与所有动画完全未改。

## 大厅

页头为“等待大厅 / 5 人局”，卡片只保留：

- 标题“房间 995270”，房号 38rpx、金色、字重 700；右侧小字“关闭房间”（仅房主）。

固定座位标题保留，卡片与标题间距保持 30rpx；座位、起立、开局条件不变。

## 边界与验证

没有后端、数据库、SQL、Nginx、认证或分享业务修改；无需 migration 或重部署后端。
凭据只在既有 MinIO 容器环境中使用，未输出、复制进本地或提交到 Git。
小程序仍没有 `assets/cards`；按现有离线包体口径估算约 0.17 MiB，实际上传以开发者工具为准。
小程序测试覆盖了大厅状态、卡牌全部 19 个 PNG、尺寸/格式/哈希、权限边界、日志与动画回归。
本轮完整 `npm test`：417 / 417 通过，无失败或跳过；`npm run check` 通过。
375px 微信模拟器已核对未满、满员、有人站立、非房主和 10 人大厅；房间卡片高 113px，
邀请 / 复制按钮宽度为 202 / 101px、高度均 37px。微信 `getImageInfo` 已实际解码
梅林、成功、失败、身份卡背与行动卡背的公网 v2 PNG，并确认尺寸。
用户随后要求暂不补充截图，已停止截图补查并恢复模拟器原登录态和网络方法。
卡牌完整加载后的视觉和真实手机清晰度不作已验证声明；单张 PNG 约 0.67～1.10 MiB，
首次下载可能比 v1 JPEG 慢，需要真机同时观察首载时间。
真实手机请重新上传体验版，比较 v1 JPG 与 v2 PNG 的身份文字、金色细框、面部、
任务成功 / 失败牌与卡背；不能把模拟器观感等同于真实手机清晰度。
