# 《圆桌秘境用户服务协议》

**版本号：1.0.1**  
**发布日期：2026年10月13日**  
**生效日期：2026年10月13日**

## 一、协议主体与适用范围

1. “圆桌秘境”（以下简称“本小程序”或“本服务”）是一款提供阿瓦隆类阵营推理桌游规则说明、人数配置、游客体验及多人在线对局辅助功能的微信小程序。本小程序由**方良军（个人开发者，以下简称“开发者”）**提供与维护。
2. 本协议是开发者与使用本服务的用户之间关于使用本服务所订立的约定。用户可在注册、登录前免费查看本协议全部内容。
3. 用户可以在不同意本协议、无需登录的情况下使用公开的游戏规则、角色说明、人数配置及本地游客体验功能。创建或加入线上房间、保存正式对局记录等依赖账号的功能需要登录。
4. 对于需要登录的功能，用户应在充分阅读本协议及《圆桌秘境隐私政策》后自主决定是否勾选同意。**未勾选不视为同意；开发者不以预先勾选或默认同意代替用户选择。**

## 二、服务内容

1. 本服务提供的主要功能可能包括：桌游规则和角色介绍；5—10人身份与任务人数配置；无账号本地五人体验局；创建、加入和管理在线房间；角色随机分配和身份提示；队长选人、组队表决、秘密任务、刺杀及胜负判定；历史战绩与对局复盘。
2. 体验玩法由本地游戏逻辑与虚拟机器人共同完成，体验数据不计入正式战绩。实际可用功能以当前小程序界面及已发布版本为准。
3. **游戏内表决、任务投票仅属于阿瓦隆桌游的组成环节，不用于社会公共议题表决、真实选举或金钱交易。**用户不得将本服务用于赌博等违法活动。
4. 本服务不承诺机器人行为具有真人水平，也不保证网络连接、终端设备或第三方基础服务在任何时间均无中断。发生故障时，开发者会在合理范围内处理与修复。

## 三、账号登录及个人资料

1. 用户自行点击微信登录并完成必要授权后，本服务根据微信登录凭证在服务端验证并取得对应的小程序用户标识（OpenID），用于识别、创建或找回本服务账号。再次登录时，通常使用同一微信身份关联既有账号。
2. 新用户可能由系统生成默认昵称及头像展示效果。用户可在个人资料页面自主设置昵称、选择微信头像或从相册选取头像。**不应将提供手机号码作为使用本服务的必要条件。**
3. 头像、昵称等资料由用户主动设置，用户应保证不侵犯第三方合法权益、不含违法违规内容；请勿在公开昵称中填写身份证号码、联系方式等不必要的个人敏感信息。
4. 用户应保护自身微信账号和登录设备安全。如发现账号异常，可通过本协议载明的联系方式联系开发者。
5. 用户可通过小程序的资料编辑功能更正可编辑信息；如需申请停止处理、删除相关个人信息或注销账号，可通过本协议载明的联系方式提出申请。开发者将在核实申请人身份后依法处理。

## 四、在线房间与游戏规则

1. 用户创建或加入线上房间后，应遵守当前房间及游戏所展示的规则。参与人数、身份能力、任务人数、组队表决、任务结果和刺杀胜负均以本服务实际规则实现为准。
2. 房间内会向其他参与者展示必要的昵称、头像、座位、游戏阶段及公开操作结果；隐藏身份、秘密任务票等内容在游戏进行中应按照规则实施访问控制。
3. **在对局结束后的历史战绩和复盘中，参与者可能按实际产品规则查看本局角色、投票及任务记录等更多信息。**用户在参与正式对局前应了解这一展示安排。
4. 用户应通过正常游戏操作参与对局，不得使用外挂、接口滥用、虚假请求或其他技术手段破坏正常的身份保密、阶段推进及公平性。
5. 用户不得使用本服务实施网络诈骗、侮辱诽谤、非法信息传播、赌博或其他违法违规行为。
