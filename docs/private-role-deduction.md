# 私人身份推测

本功能仅修改小程序。本轮 backend、SQL、数据库、API、WebSocket 协议和生产配置均未修改；不需后端重新部署。

## 使用与边界

在 TEAM_BUILDING、TEAM_VOTING、MISSION_EXECUTING、LADY_OF_LAKE 长按其他玩家头像，打开独立底部弹层。
弹层按正义/邪恶分组，只列出当前可用候选；编辑时原判断保持可选，并提供「清除推测」。
自己及系统已知具体身份的邪恶同伴不可标记；候选为空不显示空弹层，不触觉反馈。
单击仍用于选任务成员、Lady 对象、刺杀目标。组件吞掉同一次长按结束后的 tap，新的 touchstart 重置抑制状态，
不会因计时器到期误触，也不会吞掉下一次独立快点。

个人判断复用头像右下唯一 knowledge-icon，显示梅?/派?/忠?/娜?/刺?/爪?/莫?/奥?，采用较淡虚线徽记。
系统确定身份不带问号。清除推测后恢复原有月牙/候选问号或无标记。
不新增第二个身份徽记，不覆盖皇冠、完成标记、我、任务选中边框。

## 候选与数量

`presentation.roleConfig()` 为本地公开角色组成；Node 测试逐一与未修改的 GameRuleConfig 5～10 人配置比对。
`role-guesses.js` 是纯函数层，不导入请求、服务或 socket。

- 候选 = 本局公开组成 ∩ 系统私有知识允许的角色 ∩ 剩余名额。
- 剩余 = 总角色数 − 自己确定身份 − 其他确定身份 − 其他人的个人推测。
  编辑目标自身旧推测暂不扣减；忠臣按配置保留多个名额，不把所有角色当成唯一。
- 梅林：月牙只能推测本局存在的邪恶身份，但排除莫德雷德；非月牙可推测正义角色及本局存在的莫德雷德。
  自己的梅林名额已扣除，不泄露月牙玩家真实角色。
- 派西维尔：两个系统候选只允许 MERLIN/MORGANA。指定一人立即以一次本地写入设置另一人为互补身份；
  交换时同步交换，清除任意一个同时清除两人。其他玩家始终不能选这两个保留名额。
  不完整的系统候选响应暂停推测，不推断具体身份。
- 普通邪恶：系统确定的非奥伯伦同伴锁定并扣除名额；没有系统视野的玩家仍可推测剩余正义或奥伯伦。
  7 人刺客选择某人为奥伯伦后其他人不再出现奥伯伦；编辑该人仍可保留，清除后名额恢复。
- 奥伯伦：不假设其他邪恶的身份。自己的奥伯伦名额自然用完，其他候选根据公开组成计算。

## 本地隐私与生命周期

仅使用 `AVALON_ROLE_GUESSES_V1:{gameId}:{myPlayerId}`，myPlayerId 是 gamePlayerId，不是 userId。
值为 `{guesses: {"gamePlayerId": "ROLE_CODE"}}`，不持久化昵称、公开 DTO 或其他玩家的私有信息。
读取时清理不存在玩家、非法角色、自身、系统确定身份、容量超限及不完整派西配对。

推测只合并到当前设备的 displayPlayers；不写回 room.players、GameState、timeline、replay、JWT 或请求。
选择、交换、清除均不调用网络。原有公共状态 GET/刷新仍正常进行，不携带推测。
普通阶段 WebSocket 刷新保留本地判断；返回同一对局读取存储。更换 gameId/gamePlayerId 或重开等待大厅不继承旧判断。
离开页面关闭弹层，保留当前正常阶段笔记；弹层事件带作用域 nonce，过期点击不会应用到新目标/新对局。

收到 ASSASSINATION/FINISHED 的 GameState 立即删除当前存储和内存、关闭弹层，不等待 my-role/timeline。
保存删除失败不会阻止游戏同步：渲染函数仍独立禁止这些阶段的推测，同页迟到的旧快照也不能恢复已清空的作用域。
刺杀阶段仍使用原公开邪恶身份/红圈（包括奥伯伦）和黄色目标圈，不将好人身份公开。
